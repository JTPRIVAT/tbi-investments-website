Gedanken strukturieren.
Regeln in Code.

Algorithmischer Handel beginnt mit festgelegten Regeln: Ein Programm verarbeitet Informationen und führt die vorgesehenen Schritte aus. Dahinter stehen Entscheidungen darüber, welche Daten relevant sind, welche Bedingungen gelten und wie ein System auf bestimmte Situationen reagieren soll.

DAS GRUNDPRINZIP

Von der Idee zur Regel

Eine klare Beschreibung
macht eine Idee überprüfbar.

Eine Aussage wie «bei einer deutlichen Veränderung reagieren» lässt viel offen. Für ein Programm müssen Begriffe wie Veränderung, Zeitraum und Reaktion genauer beschrieben werden. Erst dadurch wird erkennbar, welche Entscheidungen eine Regel tatsächlich vorgibt.

Diese Präzision legt auch Annahmen offen. Ein Modell verwendet bestimmte Daten und betrachtet die Welt aus einem begrenzten Blickwinkel. Das Verständnis dieser Grenzen gehört zur Auseinandersetzung mit jedem algorithmischen Ansatz.

Bausteine

Daten, Regeln
und Ausführung.

01

Daten

Herkunft, Zeitbezug und Vollständigkeit beeinflussen, was sich aus Informationen ableiten lässt. Die Bedeutung eines Ergebnisses hängt deshalb auch davon ab, welche Daten ihm zugrunde liegen.

02

Regeln

Eindeutige Bedingungen verbinden eine Idee mit konkreten Schritten. Sie machen sichtbar, wann ein Programm reagieren soll und welche Fälle die Beschreibung noch nicht abdeckt.

03

Ausführung

Zur technischen Umsetzung gehören Schnittstellen, verfügbare Daten und der Umgang mit Unterbrechungen. Auch diese Rahmenbedingungen beeinflussen das Verhalten eines Programms.

Künstliche Intelligenz

Ein Werkzeug
für die Arbeit mit Informationen.

KI kann beim Strukturieren von Informationen, beim Entwerfen von Code und beim Formulieren von Analysefragen unterstützen. Mögliche Einsatzfelder reichen von internen Arbeitsabläufen bis zur Ausarbeitung erster Strategieideen. Der konkrete Zweck bestimmt, welche Unterstützung sinnvoll ist.

KI-Ausgaben können Fehler enthalten. Quellen, Berechnungen und Schlussfolgerungen bleiben deshalb überprüfungsbedürftig. Eine formulierte Strategieidee ist zunächst eine Hypothese; über ihre Tragfähigkeit entscheidet eine gesonderte Untersuchung.
