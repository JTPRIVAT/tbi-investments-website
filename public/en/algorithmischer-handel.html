Area 02 · Algorithms & AI

Give ideas structure.
Translate rules into code.

Algorithmic trading starts with defined rules: a program processes information and carries out specified steps. Behind those rules are decisions about which data matters, which conditions apply and how a system should respond to particular situations.

THE UNDERLYING PRINCIPLE

From idea to rule

A clear description
makes an idea testable.

A statement such as ‘respond to a significant change’ leaves much undefined. For a program, terms such as change, time period and response need a more precise description. That precision reveals the decisions a rule actually specifies.

It also brings assumptions into view. A model uses particular data and considers the world from a limited perspective. Understanding those boundaries is part of examining any algorithmic approach.

Building blocks

Data, rules
and execution.

01

Data

Source, timing and completeness affect what can be inferred from information. The meaning of a result therefore also depends on the data behind it.

02

Rules

Explicit conditions connect an idea to concrete steps. They show when a program should respond and which situations its description does not yet cover.

03

Execution

Technical implementation involves interfaces, available data and responses to interruptions. These operating conditions also affect how a program behaves.

Artificial intelligence

A tool
for working with information.

AI can help organise information, draft code and formulate questions for analysis. Potential applications range from internal workflows to the development of initial strategy ideas. The specific purpose determines what kind of assistance is useful.

AI outputs can contain errors. Sources, calculations and conclusions therefore still require checking. A proposed strategy starts as a hypothesis; its viability is a question for a separate investigation.
